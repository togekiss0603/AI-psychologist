AI 心理咨询师

基于知识图谱、意图识别和自然语言生成的心理咨询聊天机器人项目展示页。

项目简介

本项目后端使用 Python Sanic 提供聊天服务，结合意图分类、医疗/心理咨询知识图谱、 NER 服务和生成式回复模型来完成对话流程。

  • 前端：浏览器聊天窗口，通过 WebSocket 发送用户消息。
  • 后端：Sanic 服务监听 /chat，根据用户意图调用不同回复模块。
  • 模型依赖：BERT/UNILM、Neo4j、本地 NER 与意图识别服务。
GitHub Pages 只能托管静态网页，不能运行 Python 后端或本地模型。 当前页面已部署为项目展示和可连接的聊天前端；要让聊天真正调用模型，需要额外部署公网 WebSocket 后端，并在右侧填入 wss://... 地址。
